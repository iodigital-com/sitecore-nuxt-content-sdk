# Introduction

The Sitecore Content SDK is an open source SDK for building headless Sitecore applications. The Vue and Nuxt packages are published as `@iodigital-com/sitecore-content-sdk-vue` and `@iodigital-com/sitecore-content-sdk-nuxt`. They handle routing, rendering, and Sitecore integration. Framework-agnostic packages such as `@sitecore-content-sdk/core` and `@sitecore-content-sdk/content` stay the official Sitecore packages.

## Get started

Head over to the [Quickstart](./nuxt/quickstart) to set up your first project.
